Atualizar os dados
Kanban e auditorias do site

      

        

          Arraste aqui os arquivos exportados do site (Relatórios → Auditorias, Kanban) ou clique para escolher.

          Aceita Excel (.xlsx) e CSV, vários de uma vez. O painel reconhece sozinho o que é cada arquivo.
        

        

          
          ↗ Só abrir o site
          
        

        

          ⚡ Atualização com 1 clique (favorito) — como usar
          

            
Uma vez só: arraste este botão para a barra de favoritos do navegador (se a barra estiver escondida: Ctrl + Shift + B). Sempre que quiser atualizar: clique em “⚡ Conectar ao site” aqui, e na aba do site que abrir (já logado) clique no favorito. Ele aciona o “Sincronizar” do site e passa a mandar para este painel tudo que o site carregar (auditorias e, ao clicar em “Carregar” no Kanban, os leads).

            
⚡ FINX → painel
              

            
Se não conseguir arrastar: crie um favorito novo, dê o nome “FINX → painel” e cole o código copiado no campo do endereço (URL).
